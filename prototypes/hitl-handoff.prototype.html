Proposals to react to

  1. Leaving is not ending. ctrl+b takes you back to the task list and the HITL run stays live. If the agent is mid-turn it keeps working. When it is your turn and you are away, the task is Ready for you in the attention queue.
  2. Idle HITL runs get parked. After 30 minutes idle on your turn while you are away, or on a factory restart, the HITL run ends as parked. Reopening starts a new HITL run that resumes the same session. This widens "parked run" to mean any run ended while it waited on the operator.
  3. Typing while the agent works queues your message. Streaming input delivers it when the turn ends, and esc interrupts instead (as in Claude Code). Questions the agent asks with AskUserQuestion show as cards, never as attention requests.
  4. Grilling output is captured by hooks, not by the agent's cooperation. A PostToolUse hook attaches every write to GLOSSARY.md or docs/adr/**, and every issue URL a tool prints, to the task as an artifact. The rail shows them live: ✎ uncommitted, ✓ committed, ⊕ issue.
  5. The agent may propose. Only you hand off. The agent calls a factory tool propose_handoff(reason), which shows a banner. ctrl+h (or /handoff) works at any moment, and if the agent is mid-turn it interrupts it. A preset's HITL → AFK boundary goes through the same sheet, pre-filled by the preset.
  6. The HITL run writes its own handoff brief as its last turn: goal, what was decided, done when, out of scope, and links. It has the whole context, and the prompt cache keeps that turn cheap. You review and edit the brief on the handoff sheet. esc backs out and keeps talking, and the run never ended.
  7. The brief is the AFK run's first message and the task's goal of record. Child tasks get the brief, never the transcript.
  8. Continue as: resume (default) or fresh. Resume continues the same session, with the full transcript. Fresh starts a new session seeded with only the brief and links. The sheet pre-selects Fresh once the conversation passes 60% of the context window. Takeover then lands on the fresh session, and the old one stays readable on the task.
  9. Handoff commit. On confirm, uncommitted HITL work (glossary, ADRs) is committed to the task branch so the AFK run starts from a known point. At L2 the commit is also pushed, because the container works on a clone.
  10. An AFK run takes no chat. To talk to it you take over (the reverse of a handoff) or answer its attention requests.
  11. Quick launch is a HITL task with a quick-grill skill. It asks at most 3 questions as cards in a small overlay, then must propose the handoff. ctrl+e expands it into the full conversation, and ctrl+h hands off at any question. It ends on the same handoff sheet (L1 by default).

Settled with the operator

  • The HITL run writes its own handoff brief as its last turn. You review and edit it on the sheet.
  • Resume is the default. Fresh from brief is pre-selected past 60% of the context window.
  • A HITL run you left is parked after 30 minutes idle on your turn, or on a restart. "Parked run" widens to cover it.
  • Quick launch is a card overlay with at most 3 questions, then the same sheet, L1 by default.
  • The other proposals stand as written (no objection): hooks capture artifacts, the agent only proposes, a handoff commit is made, and an AFK run takes no chat.
